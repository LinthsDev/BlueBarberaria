# 🖊️ E-commerce Caneta Azul - Manoel Gomes

Projeto de site de e-commerce temático desenvolvido em HTML básico para a apresentação e venda de produtos exclusivos da marca **Caneta Azul**, inspirados no artista Manoel Gomes.

---

## 📌 Sobre o Projeto

Este repositório contém a estrutura de um e-commerce simples focado na navegação entre páginas e exibição de produtos personalizados. As imagens dos produtos foram geradas via Inteligência Artificial.

---

## 🛠️ Recursos e Tecnologias Utilizadas

* **HTML5:** Estruturação de todas as páginas da interface.
* **Inteligência Artificial:** Geração das imagens promocionais e dos produtos.
* **Navegação com `<a>`:** Links hipertexto (`<a href="...">`) para conectar as páginas de produtos, carrinho, login e navegação principal.
* **Imagens (`<img>`):** Inserção de mídias visuais e ícones clicáveis para redirecionamento.
* **Marcadores e Listas:** Organização de especificações de produtos e menus.
* **Tabelas:** Estruturação de dados e seleção de itens/carrinho.

---

## 📄 Páginas do Sistema

* `home.html`: Página inicial e de navegação principal.
* `login.html`: Interface de formulário para acesso de usuários.
* `Produtos.html`: Catálogo com a linha de produtos (Mouse, Bolsa, Xícara, Camisa, Travesseiro).
* `carrinho.html`: Seleção e visualização de itens escolhidos.
* `Sobre.html`: Página dedicada à apresentação e história do Manoel Gomes.
* Páginas individuais de produtos (`xícaras.html`, `camisas.html`, `mouse.html`, `Bolsa.html`, `travesseiro.html`).
